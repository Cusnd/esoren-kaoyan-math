# 条件化质量门禁

只应用与当前任务相关的门禁，不为满足清单制造无价值段落。

## 所有数学回答

- 最终结论与推导一致，变量、定义域、边界和维度没有自相矛盾。
- 解释了方法为什么自然，关键拿分步骤没有被“显然”“易得”替代。
- 只陈述有依据的来源；不确定性和假设已显式标注。
- 公式定界符成对，复杂公式和文字均可读。

## 按条件触发

- 使用定理、等价替换、换元、极限工具、矩阵变换、概率独立性或统计结论时：检查本题所需条件。
- 复杂题、证明题或满分检查：给出可在考场复现的卷面版本，并指出必须写的得分点。
- 存在更快且可靠的方法：说明适用条件与选择理由；没有实质替代解法时不强行补充。
- 用户提供错解：指出具体错误步骤、错因、后果和下次规避动作。
- OCR 有歧义：说明采用的版本；不同解释改变答案时列出差异。

## 文件门禁

- 新题已查重，章节、题目索引和 registry 三处题号一致。
- 知识点没有虚构题号；方法、公式、错题索引只在相关时更新。
- catalog、`main.tex`、`main-web.tex` 与人工目录使用同一组章节路径。
- TeX 环境和跳转接口未被破坏，没有覆盖无关用户改动。
- validator 已运行；编译或测试未运行时明确标记 `SKIP` 和原因。

## 必须返工

- 只给答案或只堆公式，导致关键依据缺失。
- 跳过会改变结论的合法性条件。
- 编造题目来源、年份或真题身份。
- 为重复题创建新 ID，或留下 registry、正文、题目索引不一致。
- 把警告、跳过或未执行的检查报告成通过。
