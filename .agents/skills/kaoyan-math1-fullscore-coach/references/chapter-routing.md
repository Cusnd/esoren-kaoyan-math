# 章节识别与跨章路由

`data/textbook_catalog.yml` 是讲次标题和文件路径的唯一事实源。本文件只保存识别信号与跨章决策，不复制路径。

## 主考章节决策

1. 以题目最终要求和决定解法的核心定理为主，不以题面中最早出现的名词为主。
2. 综合题放入承担主要推导的讲次；其他知识点通过题目、方法或公式索引交叉引用。
3. 教材讲次与通用大纲名称不一致时，使用 catalog 中的教材讲次。
4. 仍有两个同等合理章节时，选择更利于以后按题型检索的位置，并在题面说明归档判断。
